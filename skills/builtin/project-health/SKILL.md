## 工作流

1. 先用 `workspace.list`、`workspace.search` 和 `workspace.read` 确认项目类型、入口、包管理器、配置、测试和自动化脚本，不猜测未读取的内容。
2. 若项目提供安全的只读诊断命令，可用 `shell.exec` 运行版本、类型检查、测试、构建或依赖审计；当前 Shell 是特殊 WebContainer `jsh`，只使用项目实际支持的 Node.js/npm 命令。
3. 本 Skill 默认只读。不要调用写入、移动或删除工具，也不要自动修复发现的问题。
4. 把结论按严重度排序，给出具体项目相对路径、可复现证据、影响和建议；区分已验证问题、风险和未能验证的限制。
5. 最终报告只包含成功工具结果支持的事实。
